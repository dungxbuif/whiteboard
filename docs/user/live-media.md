# Share your screen

Screen sharing appears in the floating collaboration controls for signed-in
editors. It does not require joining voice.

1. Select **Share screen** to request the room's publisher slot.
2. After admission, select **Start sharing** and choose a screen or window in
   the browser picker.
3. Select **Stop sharing**, use the browser's stop control, or leave the scene
   to end the share.

Only one person can publish a screen at a time. Voice and screen media together
support ten distinct connections per room. The app captures video at up to
720p and 15 fps without microphone or system audio. Denial, cancellation, or a
full room leaves the whiteboard available.

Workspace owners must enable **Screen sharing** in enterprise feature settings.
If the feature is disabled while someone is sharing, the current share stops;
the next receiver join, signal, or stop request revokes it before media controls
are relayed. The whiteboard and voice remain connected and usable.
