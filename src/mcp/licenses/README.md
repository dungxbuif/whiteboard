# Native export font notices

These notices accompany the exact Excalidraw 0.18.1 font bytes recorded in ../render-fonts.json. No font binaries are checked in: the verified workspace dependency provides them and the renderer build verifies every SHA-256 before copying. Families are unmodified. Excalifont, ComicShanns and Xiaolai notices include the metadata comment from the pinned upstream source. Other notices come from their upstream repositories. Liberation is the legacy Ascender 2007 family (not an assumption that the newer OFL release applies); preserve its GPL2 license and special font/document embedding exceptions. Source and version of every binary are in the manifest; upstream legacy source references are maintained by https://github.com/liberationfonts/liberation-fonts/wiki . Font documents do not acquire the font's license merely by embedding it under the stated exceptions.
