# Enterprise features

The enterprise parity release is deployed on the production Whiteboard VM100
stack. Workspace owners can use comments, activity, collections, native
libraries, version history and restore, live presentation controls, domain
verification, retention policy settings and the SSO/SCIM configuration surfaces
when their provider is configured.

Production deployment status is recorded in
`docs/releases/2026-10-21-enterprise-parity-vm100.md`. Automated local
real-stack acceptance passed 8/8 flows. Production provider UAT, authenticated
deep-link browser checks and two-network media checks remain operator checks;
fixture results are not presented as production proof.
